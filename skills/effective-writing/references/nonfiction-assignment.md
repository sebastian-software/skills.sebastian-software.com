# Nonfiction Assignment and Evidence

Use this reference when a substantial piece needs an assignment brief, source
plan, or coordinated revision. A focused edit or pattern audit does not need a
separate briefing exercise.

Establish only missing context that changes the work: requested mode and
artifact, reader, purpose, channel, length, language, voice, and available
sources. Reuse supplied decisions; infer low-risk details and continue.

## Evidence boundary

Distinguish supplied facts, quotations, examples, and measured outcomes from
the author's interpretation, opinion, hypothesis, or uncertain recollection.
Keep a small evidence register when multiple sources or consequential claims
need tracking. Never invent statistics, quotations, citations, testimonials,
customer stories, personal experience, or product behavior. Mark gaps or write
within the available evidence.

For a new piece, settle its governing idea and reading path before line
polishing. For revision, address the requested problem first; use the detailed
passes in [Prose and revision](prose-and-revision.md) when the draft needs them.

## Technical-language boundary

A technical subject alone does not require controlled language. Preserve exact
terms and qualifications while writing natural editorial prose. A named
controlled-language contract belongs to technical documentation in
`effective-delivery`. If a requested assurance or style conflicts with the
artifact's language or purpose, explain that conflict and preserve the user's
intended result without making an invalid conformance claim.

## Deliverable

Return the requested draft, revision, or critique first, followed by material
source gaps or unresolved author decisions. Add title, lead, ending, or call to
action alternatives only when useful to the requested choice. For an audit,
give prioritized patterns, representative evidence, reader effects, and small
correction directions; revise only when the user also requested revision.
Never infer AI authorship from prose patterns.
